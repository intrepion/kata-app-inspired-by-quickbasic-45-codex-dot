BYTEWELL FIELD GUIDE
Small language. Big possibilities.
An independent learning workbench inspired by QuickBASIC 4.5's edit, run, and inspect loop. This is a focused BASIC dialect, not a DOS emulator or a compatible QuickBASIC compiler.
Write & explore
One statement per line. Names are case-insensitive. Numbers use floating-point arithmetic; add $ to a variable name for a string. Line numbers and labels on their own line are optional.
name$ = "Ada"
FOR i = 1 TO 5
  PRINT name$; i ^ 2
NEXT i
Control the flow
IF … THEN … ELSE … on one line, or block IF / ELSE / END IF. FOR / NEXT with STEP, WHILE / WEND, GOTO, GOSUB / RETURN, END and STOP.
Strings & math
+ − * / \ MOD ^, comparisons, AND OR NOT. ABS INT SQR SIN COS LEN STR$ VAL CHR$ ASC LEFT$ RIGHT$ MID$ RND. Angles use radians. RND or RND() returns 0 ≤ n < 1.
Read & draw
PRINT / ? uses semicolons to join output and commas for 14-column zones. INPUT "Prompt"; value pauses for one value. CLS clears output. COLOR foreground, background uses palette colors 0–15.
SCREEN 12
LINE (20, 20)-(200, 100), 11, B
CIRCLE (320, 240), 90, 14
PSET (320, 240), 15
SCREEN 12 is a 640 × 480 canvas. SCREEN 0 returns to text. LINE accepts B for a box or BF for a filled box. Graphics are illustrative, not hardware emulation.
Know the edges
No arrays, SUB/FUNCTION definitions, DO/LOOP, SELECT CASE, file I/O, sound, EXE compilation, DOS calls, colon-separated statements, or numeric type suffixes. Imported files must use this subset. Unsupported statements show a line-numbered error.
Safe to experiment. 100,000 statements per run, 64 KiB text output, 10,000 shapes. Pause keeps your place. Editing or opening a program resets the runtime. Save keeps one browser draft; Export creates a portable .bas file.
